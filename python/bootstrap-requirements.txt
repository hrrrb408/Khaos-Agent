# Bootstrap toolchain pinned with hashes (Batch 9.7b, round-9 review §二十一).
#
# CI jobs previously installed uv via ``python -m pip install uv==0.12.5``
# with no hash verification.  A compromised PyPI mirror or download link
# could replace the same-version wheel and control every subsequent
# frozen install.  This file is the trust root for the uv binary: install
# with
#
#     python -m pip install --require-hashes -r python/bootstrap-requirements.txt
#
# pip refuses any wheel whose sha256 is not listed below, so a swapped
# wheel fails to install.  uv is a single Rust binary (PyOxidizer) with
# NO Python runtime dependencies (Requires-Dist is empty), so hashing
# the uv wheels alone is sufficient — there is no transitive dependency
# tree that also needs pinning.
#
# Note: pip-audit is NOT in this file.  It has a heavy dependency tree
# (CacheControl, cyclonedx-python-lib, etc.) that would all need hash
# pinning and frequent updates.  pip-audit is installed separately in the
# supply-chain-audit workflow, where it is the AUDIT TOOL rather than the
# trust root — the trust root for business dependencies is pip-audit's
# own --require-hashes verification of the frozen requirements-lock.txt.
#
# Update procedure: when bumping uv, fetch the new hashes from
#   https://pypi.org/pypi/uv/<version>/json
# and replace the lines below IN FULL.
