# M6 Security Architecture Closure Report

Status: **NOT CLOSED (evidence incomplete)**

This checked-in report is intentionally a non-green template. The exact
commit-bound report is generated by
`scripts/build_m6_closure_report.py` in the Security Closure evidence job.
It records every M6 finding's root cause, invariant, modified files,
pre-repair exploit path, post-repair boundary, tests, and evidence class.

Closure is forbidden until all of the following are present together:

- exact-commit `Security Closure Gate` and `Product Integrity Gate` success;
- real macOS launchd/XPC and Windows Service-SID/Named Pipe proof artifacts;
- independent resource-oracle evidence for every `CLOSED` lifecycle result;
- exact approved-effect evidence for every `SUCCESS` result.

Missing, skipped, cancelled, unavailable, or mock evidence remains
`UNKNOWN`, `QUARANTINED`, or `FAILED`; it cannot be promoted to `CLOSED`.
The current single-maintainer repository also does not claim independent
human review. See the generated artifact for the exact commit SHA, test
counts, CI run id, and native evidence paths.
